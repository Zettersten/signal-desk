# Signal Desk design

The workspace is graphite under low ambient light, with blue-gray depth and a single ice-blue action color. Amber marks high importance, never definitive risk. The workspace is a fixed navigation rail next to a dense, horizontally aligned reading queue. App controls borrow macOS conventions, but window placement, translucency and notifications belong to the host OS. The orbital line plate is an original, decorative vector; it is not live telemetry or a coverage map. The compact view removes the orbital plate and navigation rail and becomes an inbox. No gradients or outlined cards.

Library profiles use aligned tables and a short activity list. Record and quote windows keep the operating system’s own window decorations, with one content scroller and a restrained serif reading face. Amber highlights mark saved quotations inside the source text; the scrapbook lists quotes separately from user notes.
